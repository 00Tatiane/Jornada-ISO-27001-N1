# Jornada-ISO-27001-N1
Projeto educacional interativo criado para ensinar os conceitos básicos da ISO/IEC 27001 de forma simples e visual. O objetivo é oferecer um treinamento em nível iniciante, com módulos interativos, desafios rápidos e quiz final, facilitando o entendimento sobre SGSI, auditorias e controles de segurança da informação.

## 🎯 Objetivo

Fornecer um treinamento introdutório sobre:
- SGSI (Sistema de Gestão da Segurança da Informação)
- Ciclo de auditorias
- Diferença entre acreditação e certificação
- Conceitos normativos e informativos

## 🚀 Tecnologias utilizadas

- HTML5  
- CSS3  
- JavaScript (Vanilla)
